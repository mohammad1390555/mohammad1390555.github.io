# Mohammad — Personal Portfolio

A lightweight, single-file bilingual Persian/English portfolio for GitHub Pages.

**Live site:** https://mohammad1390555.github.io/  
**Public projects shown:** 23  
**Languages:** Persian and English, with a saved language preference.

## Features

- Responsive, clean blue theme with a compact mobile layout.
- Search, language filtering and sorting by recommended order, stars, or name.
- Project cards include repository links, verified demos and available star counts.
- Contact links for Telegram, Instagram and X.
- SEO metadata, social-sharing metadata and Person structured data.
- Keyboard skip link, visible focus states, reduced-motion support and a back-to-top control.
- Client-side measures that discourage ordinary text copying while keeping search controls usable.
- No external fonts, scripts, images or build dependencies.

The site is a static HTML page. Update `index.html` and commit to the `main` branch to publish changes through the existing GitHub Pages setup.
